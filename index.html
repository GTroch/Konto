Arbeitsblatt: Die Klasse Konto.java selbst programmieren

Eine Schritt-für-Schritt-Anleitung zur objektorientierten Programmierung in Java

🎯 Lernziele

  • Du kannst eine Java-Klasse mit Attributen, Konstruktor und Methoden selbst schreiben.
  • Du verstehst den Unterschied zwischen Attributen, Getter- und Setter-Methoden.
  • Du kannst eine if-Bedingung einsetzen, um Kontooperationen zu prüfen.
  • Du kannst Objekte erstellen und deren Methoden aufrufen.

📚 Einleitung

In dieser Aufgabe baust du eine Klasse für ein einfaches Bankkonto nach. Ein Konto kennt seinen Inhaber und seinen aktuellen Kontostand. Es kann Geld annehmen (einzahlen), Geld ausgeben (abheben) und seinen Stand auf der Konsole anzeigen.

Du arbeitest dich Schritt für Schritt durch die Aufgabe. Am Ende jedes Schritts steht eine kleine Aufgabe, die du direkt in deine Entwicklungsumgebung einträgst.

📌
So arbeitest du: Öffne deine Entwicklungsumgebung (z. B. BlueJ oder IntelliJ IDEA) und lege eine neue Datei Konto.java an. Schreibe den Code jedes Schritts selbst ab — das Abtippen hilft dir, den Code zu verstehen!

🔧 Schritt für Schritt

1
Die Klassenhülle anlegen

Jede Java-Klasse beginnt mit dem Schlüsselwort public class, gefolgt vom Klassennamen. Der gesamte Inhalt steht zwischen zwei geschweiften Klammern { }.

Der Klassenname muss exakt mit dem Dateinamen übereinstimmen:

public class Konto {
    // Hier kommt dein gesamter Code rein
}
💡
Merke: Die äußere geschweifte Klammer { öffnet die Klasse, die letzte } schließt sie. Alles — Attribute, Konstruktor, Methoden — befindet sich dazwischen.
✏️
Deine Aufgabe: Erstelle die Datei Konto.java und schreibe die Klassenhülle. Speichere die Datei. Prüfe, ob das Programm fehlerfrei kompiliert.
2
Attribute (Instanzvariablen) hinzufügen

Attribute sind Variablen, die zu einem Objekt gehören. Sie speichern den Zustand des Objekts — also alle Informationen, die ein Konto beschreiben.

Unser Konto braucht zwei Attribute:

AttributnameDatentypBedeutung
inhaberStringName des Kontoinhabers (Text)
kontostanddoubleAktuelles Guthaben in Euro (Dezimalzahl)

Attribute werden direkt nach der öffnenden Klammer der Klasse deklariert:

public class Konto {
    String inhaber;
    double kontostand;
}
💡
Warum double und nicht int? Geldbeträge können Cent-Beträge haben (z. B. 12,50 Euro). Der Typ double kann Dezimalzahlen speichern, int nur ganze Zahlen.
✏️
Deine Aufgabe: Füge die beiden Attribute in deine Klasse ein. Achte auf den richtigen Datentyp und das Semikolon am Ende jeder Zeile.
3
Den Konstruktor schreiben

Der Konstruktor ist eine spezielle Methode, die automatisch aufgerufen wird, wenn man ein neues Objekt mit new Konto(...) erstellt. Er legt die Anfangswerte der Attribute fest.

💡
Besonderheiten des Konstruktors:
  • Er heißt genauso wie die Klasse (hier: Konto).
  • Er hat keinen Rückgabetyp (kein void, kein int, …).
  • Er wird mit public eingeleitet.

Unser Konstruktor bekommt zwei Parameter: den Namen und den Startbetrag:

public Konto(String name, double startBetrag) {
    inhaber = name;           // Attribut ← Parameter
    kontostand = startBetrag; // Attribut ← Parameter
}

So wird der Konstruktor benutzt: Mit new Konto("Anna", 1000.0) wird ein Objekt erzeugt. Dabei werden automatisch inhaber = "Anna" und kontostand = 1000.0 gesetzt.

✏️
Deine Aufgabe: Füge den Konstruktor in deine Klasse ein. Deine Klasse sollte jetzt so aussehen: 
public class Konto {
    String inhaber;
    double kontostand;

    public Konto(String name, double startBetrag) {
        inhaber = name;
        kontostand = startBetrag;
    }
}
4
Die Methode einzahlen schreiben

Methoden beschreiben, was ein Objekt tun kann. Die Methode einzahlen erhöht den Kontostand um einen bestimmten Betrag. 

public void einzahlen(double betrag) {
    kontostand = kontostand + betrag;
}
💡
Erklärung Zeile für Zeile:
  • public void — die Methode ist öffentlich zugänglich und gibt nichts zurück
  • einzahlen — der Name der Methode
  • (double betrag) — die Methode erwartet eine Dezimalzahl als Eingabe
  • kontostand = kontostand + betrag; — der alte Stand plus der eingezahlte Betrag ergibt den neuen Stand

Beispiel: Wenn kontostand = 1000.0 und du rufst einzahlen(500.0) auf:

kontostand = 1000.0 + 500.0  // → kontostand wird 1500.0
✏️
Deine Aufgabe: Füge die Methode einzahlen in deine Klasse ein.
5
Die Methode kontostandAusgeben schreiben

Diese Methode soll eine freundliche Meldung mit dem aktuellen Kontostand auf der Konsole ausgeben: 

public void kontostandAusgeben() {
    System.out.println("Der Kontostand X beträgt: " + kontostand + " Euro");
}
💡
Wie funktioniert System.out.println? Es gibt den Text in Klammern auf der Konsole aus und springt danach in eine neue Zeile. Mit dem +-Zeichen werden Text-Teile und Variablenwerte zu einem einzigen String zusammengesetzt.
⭐
Bonus-Aufgabe: Das X im Text ist ein Platzhalter. Kannst du es durch den echten Namen des Inhabers ersetzen? Nutze das Attribut inhaber!

Gewünschte Ausgabe:
Der Kontostand Anna beträgt: 1500.0 Euro
✏️
Deine Aufgabe: Füge die Methode kontostandAusgeben in deine Klasse ein.
6
Getter-Methoden schreiben

Getter sind Methoden, die den Wert eines Attributs nach außen weitergeben. Sie beginnen immer mit get und dem Attributnamen.

Warum brauchen wir Getter? Wenn eine andere Klasse den Kontostand lesen möchte, geht das über den Getter — sie greift damit nicht direkt auf das Attribut zu. 

public double getKontostand() {
    return kontostand;
}

public String getInhaber() {
    return inhaber;
}
💡
Wichtige Regel: Der Rückgabetyp (z. B. double oder String) muss zum Typ des Attributs passen, das zurückgegeben wird. Das Schlüsselwort return sendet den Wert zurück an den Aufrufer.
MethodeRückgabetypWas sie zurückgibt
getKontostand()doubleDen aktuellen Kontostand
getInhaber()StringDen Namen des Inhabers

Beispiel für die Verwendung:

Konto k = new Konto("Anna", 1000.0);
System.out.println(k.getKontostand()); // Ausgabe: 1000.0
System.out.println(k.getInhaber());    // Ausgabe: Anna
✏️
Deine Aufgabe: Füge beide Getter-Methoden in deine Klasse ein.
7
Setter-Methoden schreiben

Setter ermöglichen es, den Wert eines Attributs von außen zu verändern. Sie beginnen immer mit set und dem Attributnamen. 

public void setInhaber(String neuerName) {
    inhaber = neuerName;
}

public void setKontostand(double neuerStand) {
    kontostand = neuerStand;
}
💡
Getter vs. Setter:
  • Getter → liest einen Wert → hat einen Rückgabetyp (z. B. double) → kein Parameter
  • Setter → verändert einen Wert → hat void als Rückgabetyp → hat einen Parameter
✏️
Deine Aufgabe: Füge beide Setter-Methoden in deine Klasse ein.
8
Die Methode abheben mit einer Bedingung

Beim Abheben gibt es eine wichtige Regel: Man kann nur Geld abheben, wenn genug Guthaben vorhanden ist. Dafür brauchen wir eine if-Bedingung: 

public void abheben(double betrag) {
    if (kontostand >= betrag) {
        kontostand = kontostand - betrag;
    }
}
💡
So funktioniert die if-Bedingung:
  • if (Bedingung) { ... } — der Code in { } wird nur ausgeführt, wenn die Bedingung wahr ist
  • >= bedeutet "größer oder gleich"
  • Ist nicht genug Geld vorhanden, wird der Code in { } einfach übersprungen

Beispiel:

KontostandBefehlBedingungErgebnis
1000.0 €abheben(300.0)1000 ≥ 300 ✓Kontostand: 700.0 €
700.0 €abheben(900.0)700 ≥ 900 ✗Kontostand bleibt: 700.0 €
✏️
Deine Aufgabe: Füge die Methode abheben in deine Klasse ein.
9
Die Klasse testen

Jetzt ist deine Klasse fertig! Teste sie mit folgendem Code (z. B. in einer main-Methode oder direkt in BlueJ): 

Konto k = new Konto("Anna", 1000.0);  // Konto erstellen
k.einzahlen(500.0);                        // 500 Euro einzahlen
System.out.println("Der Kontostand A beträgt: " + k.getKontostand() + " Euro");
k.kontostandAusgeben();

Erwartete Ausgabe auf der Konsole:

Der Kontostand A beträgt: 1500.0 Euro
Der Kontostand X beträgt: 1500.0 Euro

(Das "X" bleibt stehen, bis du die Bonus-Aufgabe aus Schritt 5 gelöst hast.)

✏️
Weitere Testaufgaben:
  • Erstelle ein zweites Konto für "Ben" mit einem Startbetrag von 500.0 Euro.
  • Zahle 200.0 Euro auf Bens Konto ein. Gib den neuen Stand aus.
  • Hebe 100.0 Euro von Bens Konto ab. Was ist der neue Kontostand?
  • Versuche 800.0 Euro von Bens Konto abzuheben. Was passiert? Erkläre warum.
  • Ändere den Inhaber von Bens Konto mit setInhaber(...) auf "Benjamin". Lass den Inhaber mit getInhaber() ausgeben.
  • Bonus: Setze den Kontostand mit setKontostand(0.0) auf null und hebe danach 1.0 Euro ab. Was passiert?
🔒 Musterlösung — vollständige Klasse Konto.java (Erst anschauen, wenn du fertig bist!) 
public class Konto {
    String inhaber;
    double kontostand;

    public Konto(String name, double startBetrag) {
        inhaber    = name;
        kontostand = startBetrag;
    }

    public void einzahlen(double betrag) {
        kontostand = kontostand + betrag;
    }

    public void kontostandAusgeben() {
        System.out.println("Der Kontostand " + inhaber + " beträgt: " + kontostand + " Euro");
    }

    public double getKontostand() {
        return kontostand;
    }

    public String getInhaber() {
        return inhaber;
    }

    public void setInhaber(String neuerName) {
        inhaber = neuerName;
    }

    public void setKontostand(double neuerStand) {
        kontostand = neuerStand;
    }

    public void abheben(double betrag) {
        if (kontostand >= betrag) {
            kontostand = kontostand - betrag;
        }
    }
}
